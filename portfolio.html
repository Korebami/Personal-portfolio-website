The Architecture

Every project is a building block

The UAV work provides the sensing infrastructure. The battery degradation work provides the lifecycle modeling methodology. The SMR work proves that methodology generalizes to entirely different physical domains. Together, they form a coherent framework for physics-informed digital twin systems that make autonomous decisions based on expected remaining useful life.

The autonomous rover and future work will extend this to mobile ground platforms — closing the loop between aerial sensing, lifecycle-aware actuation, and real-time decision support.
