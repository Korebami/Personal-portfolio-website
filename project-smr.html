Overview

Proving the methodology generalizes

The design architecture of a cyber-physical small modular reactor (SMR) emulator enables real-time control and grid interaction analysis without requiring access to an actual reactor. This is a lifecycle monitoring system structurally analogous to the electric aircraft battery framework — but applied to an entirely different physical domain.

Where the aircraft work asks "how does battery degradation affect flight economics?", the SMR work asks the parallel question: "how does component lifecycle state inform reactor output and maintenance decisions, and how does that ripple into grid-level interaction?"

System Architecture

Real-time control loop & grid interaction

The emulator models the reactor's physical behavior, estimates component health and expected output capacity, and feeds that into control decisions that determine how the system interacts with the grid in real time.

Cyber-Physical Control Architecture
Why an Emulator

Testing control strategy safely

A cyber-physical emulator allows real-time control and grid-interaction strategies to be tested and refined without the cost, risk, or access constraints of a physical reactor — critical for a technology still scaling toward commercial deployment.

01

Real-time control loop validated against emulated physical dynamics before any hardware-in-the-loop testing.

02

Grid interaction modeled explicitly, not abstracted away — output decisions are made with grid-level consequences in view.

Status

Awaiting publication

The full paper, "Design Architecture of a Cyber-Physical Small Modular Reactor Emulator for Real-Time Control and Grid Interaction," is in press for ASME IDETC 2025. Full citation details will be added once the conference proceedings are published.

How This Connects

Proof that the framework generalizes

The same architecture pioneered in the electric aircraft battery degradation work — physics modeling → lifecycle estimation → informed decision — is demonstrated here in a completely different physical domain. That's the strongest evidence yet that this is a genuine methodology, not a one-off solution.
